# Новое приложение для личного кабинета

Это новая фича для личного кабинета клиента, которая показывает несколько последних успешных банковских операций клиента.

### Инсрукция по установкеЖ
1. Создать форк репозитория [GitHub](https://github.com/svetlana-kolesnikova/Last_operayion_9.1)

2. Убрать галочку с "Copy the main brunch only"

3. Скопировать код по ssh-ключу, либо по токену.

4. В локальном EDI вставить ключ

### Описание работы программы:

- Программа приветствует пользователя и предлагает выбрать формат файла для получения транзакций.

- Программа предлагает пользователю выбирать статус интересующих его операций.

- Программа предлагает пользователю отсортировать транзакции по дате (по возрастанию/по убыванию).

- Программа предлагает пользователю вывести только рублевые транзакции.

- Программа предлагает пользователю отфильтровать транзакции по значению ключа "description".

- Программа распечатывает итоговый список транзакций

### Описание функций:

 - Функция get_mask_card_number принимает на вход номер карты и возвращает ее маску. Номер карты замаскирован и отображается в формате
   XXXX XX** **** XXXX, где X — это цифра номера.

 - Функция get_mask_account принимает на вход номер счета и возвращает его маску. Номер счета замаскирован и отображается в формате
   **XXXX, где X — это цифра номера.

 - Функция mask_account_card на вход номер счета или номер карты и возвращает его маку. Примеры работы функции:
   ##### Пример для карты
   Visa Platinum 7000792289606361  # входной аргумент
   Visa Platinum 7000 79** **** 6361  # выход функции

   ##### Пример для счета
   Счет 73654108430135874305  # входной аргумент
   Счет **4305  # выход функции

 - Функция-генератор card_number_generator создаёт номера банковских карт в формате 
   XXXX XXXX XXXX XXXX

 - Функция-генератор transaction_descriptions принимает список словарей с транзакциями и 
   возвращает описание каждой операции по очереди.

 - Функция filter_by_currency возвращать итератор, который поочередно выдает транзакции, где валюта операции 
   соответствует заданной (например, USD). 

 - Функция reader_csv для чтения файла csv. Возвращает список словарей с транзакциями.

 - Функция reader_excel для чтения файла excel. Возвращает список словарей с транзакциями.

 - Функция search_operation_by_description для поиска в списке словарей операций по заданной строке "description".

 - Функция transactions_counter_by_type для подсчёта количества банковских операций определенного типа.
 - Функция sorted_by_rub сортирует транзакции по значению "RUB".
